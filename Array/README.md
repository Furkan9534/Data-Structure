## 🇬🇧

This folder contains examples of the same data structure
implemented in multiple programming languages.

The goal is:

- to show language differences
- to explain when and why this data structure should be chosen

### When should I use Array / List?

- When data is ordered
- When fast index-based access is required
- When the size does not change very frequently
